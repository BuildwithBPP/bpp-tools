Writing a new SOP

  1. Copy the shape of the Website Development SOP: the flow at a glance, who does what, the rules, each stage with a "done when", what to do when things go sideways, and a list of terms.
  2. Write it so someone new could run it on their first day. Short steps, plain words, the exact lines to say.
  3. Save the markdown file in SharePoint next to the work it covers, and add a hub page if the team will use it often.
  4. Add it to this page under its department. If it replaces an older SOP, mark the old one.
  5. Keep client names, amounts owed and passwords off hub pages. The hub is public.

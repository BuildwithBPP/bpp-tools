AI Employee Plugins · Architecture
Each plugin = one employee. Skills inside = that employee’s tasks.

The model: A plugin is the umbrella for an AI employee. Skills inside are the tasks that employee handles. Teammates run claude plugin install [path] and get the entire role in one command. Replaces the loose-skills approach because shipping a "Marketing Coordinator" to Eli is one command, not ten setup steps.

The first plugin (bpp-content-producer) shipped 2026-04-30 at c:/Users/dtben/Developer/bpp-plugins/. The other five are queued for Q2 2026.
